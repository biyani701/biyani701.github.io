# biyani701.github.io

This repository publishes **[www.biyani.xyz](https://www.biyani.xyz)** through GitHub Pages, from its `gh-pages` branch.

The site is built from [`apps/hub`](https://github.com/biyani701/vishal-portfolio/tree/main/apps/hub) in
[biyani701/vishal-portfolio](https://github.com/biyani701/vishal-portfolio). That repository's `hub-ci.yml` workflow
publishes each build here as a single commit, so don't edit `gh-pages` by hand. Change the hub there instead.

Other repositories' GitHub Pages sites are served under `www.biyani.xyz/<repo>/`.
